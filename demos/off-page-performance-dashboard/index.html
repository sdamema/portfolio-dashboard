DATA GUIDE

Prepare your file

Google Sheets and CSV files use the same columns. You do not need every field, but missing data can limit parts of the report.

01

Choose the right level of detail

Start with the recommended fields if you want every report page to be useful.

MINIMUM TO LOAD

One recognised main column

The file needs a header row, at least one data row and one of these columns:

Campaign NameArticle URLReferring Domain
This opens the dashboard, but it is not enough for a complete report.

RECOMMENDED FOR THE FULL REPORT

Use the complete working set

02

Column names can vary

Use the recommended name or any accepted alternative below.

DatePublication Date, Published Date, Data

Matching is flexible. Uppercase and lowercase do not matter. Spaces, underscores and dashes are treated in the same way. Extra columns are kept in the source but are not used in the report.

Use New RD only once. Enter “Yes” on the first row where a publisher becomes new to the reporting dataset. Later links from the same domain should be “No”.

03

What happens when data is missing

The import does not fail for every gap. The dashboard uses a fallback where it can.

Referring Domain

Read from a valid Article URL. Without either field, publisher results are incomplete.

Year or Week

Read from Date when it contains a valid date. Otherwise the weekly trend is incomplete.

Campaign Name

The row is grouped under “Unassigned”.

Campaign Topic

The row is grouped under “Uncategorised”.

Source Flow

The row is grouped under “Unspecified”, so Outreach types cannot classify it.

DR

Authority metrics use only rows with a valid score and may show “—” when none is available.

Article URL

The placement cannot be opened and the data check reports a missing or invalid link.

Optional fields

The dashboard loads normally; only the related metric or detail is unavailable.

When does the import stop?

If the file has no data rows, or if none of Campaign Name, Article URL and Referring Domain is recognised, the dashboard shows an error and asks you to check the headers.

    Key terms

    Backlinks
    Total backlink rows left after applying the filters.
    Domain Rating (DR)
    A 0–100 score used to estimate the strength of a publisher domain. It must be included in the source data; the dashboard does not calculate it.
    New domains
    Unique referring domains marked “Yes” on their first appearance in the reporting dataset.
    Median DR
    The middle DR value when all values are sorted. It shows a typical score without giving too much weight to very high or low values.
    Average DR
    The average publisher DR across backlinks with a recorded score.
    DR 50+ share
    Percentage of selected backlinks from publishers with DR 50 or higher. It tracks how much activity comes from stronger domains, but DR alone does not measure link quality.
    Backlinks / article
    Average number of backlinks per unique published article.
    Publisher concentration
    Percentage of selected backlinks coming from the five most-used publisher domains. A high value means the results depend heavily on a small group of publishers.
    Active weeks
    Number of weeks in which a publisher appears in the data.
    4-week average
    The average weekly value across the latest four weeks. It makes one-off peaks easier to spot.
    Data completeness
    Checks whether seven core reporting fields are filled in and reduces the score for possible duplicates.
    Editorial outreach
    Direct pitching to selected publications to secure relevant coverage and backlinks.
    Digital PR
    Stories, data or creative campaigns designed to earn coverage and links from several publications.
    Volume outreach
    Faster, repeatable placements focused on generating more links, usually from lower-DR publications.
    Average relevance
    Average topical relevance score for rows where this optional value is provided.
    Cost / link
    Average recorded cost for each backlink row.
    Live rate
    Percentage of links with a status of Live, Active or Published.
